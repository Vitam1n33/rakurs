# Ракурс — сайт онлайн-школы фотографии

Одностраничный сайт-визитка: курсы и цены с избранным, примеры фото и интерактивный видоискатель, где можно покрутить свет и фокус и «нажать на спуск».

Статический HTML и CSS, без сборки и зависимостей. Чтобы посмотреть сайт, открой `index.html` в браузере.

- `index.html` — разметка и скрипты
- `styles.css` — стили, светлая и тёмная тема
- `фото/` — снимки для видоискателя и галереи

Школа, цены и контакты на сайте вымышленные, это демо.
